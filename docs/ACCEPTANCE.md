# AgentCtrlV 手动验收清单

每完成一个里程碑，按下列场景逐项验证。

---

## 场景 1：热启动单选（M2）

1. 打开 ChatGPT Desktop，确保已登录且输入框可见
2. 复制一张图片到剪贴板
3. 按 Alt+V
4. 点击 ChatGPT
5. **预期**：
   - 图片出现在 ChatGPT 输入框
   - 原剪贴板内容已恢复
   - 菜单关闭
   - 无崩溃、无静默失败

---

## 场景 2：冷启动新会话（M3）

1. 完全关闭 ChatGPT Desktop（任务管理器确认无进程）
2. 复制一张图片
3. 按 Alt+V，点击 ChatGPT
4. **预期**：
   - ChatGPT 启动
   - 出现新会话（或按配置触发新会话）
   - 图片出现在输入框
   - 超时 8s 内完成，否则有通知

---

## 场景 3：多选（M3）

1. 复制图片
2. 按 Alt+V
3. Ctrl+点击 ChatGPT，Ctrl+点击 Cursor
4. 按 Enter（或点中心）
5. **预期**：
   - 两个 Agent 依次收到图片
   - 间隔约 800ms
   - 每个成功/失败都有汇总通知

---

## 场景 4：文本注入（Windows Terminal）

1. 打开 Windows Terminal
2. 复制一段文本
3. Alt+V → 选 Windows Terminal
4. **预期**：文本粘贴到当前终端，不自动回车

---

## 场景 5：剪贴板恢复

1. 剪贴板放一张图片
2. 执行任意一次成功注入
3. 打开记事本，Ctrl+V
4. **预期**：仍然是原来的图片（不是被覆盖）

---

## 场景 6：热键冲突

1. 用其他工具占用 Alt+V
2. 启动 AgentCtrlV
3. **预期**：托盘气泡提示冲突，允许修改热键，其他热键仍可用

---

## 场景 7：取消操作

1. 按 Alt+V 弹出菜单
2. 按 Esc 或点击空白
3. **预期**：菜单关闭，无任何注入，剪贴板不变

---

## 场景 8：失败可见（注入失败）

1. 目标窗口处于全屏独占或特殊状态导致注入失败
2. **预期**：有托盘通知，说明可能失败，并保留 Payload 可重试

---

## Mock 验收（M1）

1. 打开记事本
2. 复制图片
3. 运行 M1 脚本
4. **预期**：图片出现在记事本，原剪贴板恢复
